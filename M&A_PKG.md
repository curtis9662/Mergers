

# M&A Due Diligence & Security Validation Execution Guide

When a new organization is acquired or during the due diligence phase, it is critical to validate the security posture and governance protocols of the target entity. Please execute the following sequence to generate the necessary compliance and technical artifacts.

## Step 1: Execute GRC Validation Script

Run the automated Mergers & Acquisitions Governance, Risk, and Compliance (GRC) validation script. This PowerShell script maps out inherited technical debt and identifies baseline security passes and failures.

* **Script Link:** [MA_GRC_Validation_v2.ps1](https://github.com/curtis9662/Mergers/blob/MERGErs/MA_GRC_Validation_v2.ps1)
